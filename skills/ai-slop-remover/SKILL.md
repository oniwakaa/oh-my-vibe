# AI Slop Remover

The `/ai-slop-remover` command is a polishing tool. It removes the "AI fingerprints" from the code—the redundant explanations, the overly cautious comments, and the generic patterns that identify code as being generated by an LLM.

The agent will focus on:

1. **Removing Redundant Comments**: Deleting comments that explain *what* the code does (which should be obvious from the name) instead of *why* it does it.
2. **Eliminating Clichés**: Removing phrases like "It is important to note that...", "Ensure that...", or generic "Helper function to..." headers.
3. **Simplifying Over-Engineered Patterns**: Replacing overly verbose AI-style structures with concise, idiomatic patterns used by senior engineers.
4. **Preserving Logic**: Ensuring that not a single line of functional logic is changed during the removal of "slop."

## Usage

```
/ai-slop-remover
```

## When to Use
- As the final step before marking a task as `completed`.
- After a `deep` agent has finished a large implementation.
- Before handing off code for a human review.

## Success Criteria
The code looks as if it were written by a disciplined senior engineer who values brevity and clarity over verbosity.
